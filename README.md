# Suproc Listing Optimizer

A production-ready B2B supplier listing auditor and optimization agent built for industrial marketplaces. It analyzes supplier raw text, extracts structured specifications, enforces zero-trust grounding against unverified fabrications, and scans live IndiaMART competitor listings for market benchmarks.

---

## 🏗 Architecture & File Layout

```
├── backend/
│   ├── main.py           # FastAPI server & route handlers (/api/analyze, /health)
│   ├── llm_providers.py  # Provider abstraction (Groq / Gemini / Claude / OpenAI) & B2B prompt
│   ├── guardrail.py      # Zero-trust verification & unverified claim sanitization
│   ├── apify_client.py   # IndiaMART scraper integration with 24h category caching
│   ├── config.py         # Environment configuration (reads os.environ exclusively)
│   └── logging_store.py  # Call logging & admin auth middleware (X-Admin-Token)
└── frontend/             # Production React + Vite dashboard
    ├── src/
    │   ├── App.jsx       # Main layout, API client, state & reset handlers
    │   └── components/   # InputForm, ResultsView, ErrorBanner
    ├── README.md         # Frontend Vercel deployment & setup docs
    └── vercel.json       # SPA routing configuration
```

## 🚀 How to Use (Step-by-Step Setup)

### 1. Start the Backend (FastAPI)

```bash
cd backend

# Create & activate virtual environment
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Create environment config
cp .env.example .env
```

Set your environment variables in `backend/.env`:
- `LLM_PROVIDER`: `gemini` | `groq` | `claude` | `openai`
- `GEMINI_API_KEY` (or key matching your chosen provider)
- `APIFY_TOKEN`: Your Apify API token (for competitor scanning)
- `ADMIN_TOKEN`: Secret token for admin endpoints

Launch the backend server:
```bash
uvicorn main:app --port 8000
```
Verify backend health at `http://localhost:8000/health`.

### 2. Start the Frontend (Vite + React)

Open a new terminal window:
```bash
cd frontend

# Install packages
npm install

# Run dev server
npm run dev
```

Open **`http://localhost:5173`** in your browser.

## 💡 Using the Web Application

1. **Submit Listing**: Select category (Garments, Chemicals, Electronics, General/Other), paste your raw supplier text, and optionally enter structured specs (MOQ, Lead time, Certifications, Price tiers).
2. **Audit & Review**: Click **Audit & Optimize Listing** to view:
   - 6-criterion discoverability scorecard (0–10).
   - Optimized B2B listing preview (Title, Overview, Key Specifications table, CTA).
   - Automatically removed unverified claims (if any were detected).
3. **Interactive Missing Specs (Re-run)**: Fill in any missing required specs in the inline prompt card and click **Add these details and re-run** to instantly update the audit.
4. **Clean Reset**: Click **Analyze Another Listing** in the top bar to reset all state instantly without reloading the browser page.

## ⚠️ Important User Disclaimers & Rules

> [!IMPORTANT]
> **1. Zero-Trust Grounding Rule**  
> The optimizer strictly forbids inventing specs. If a specification (e.g. MOQ, Lead time, GSM, Certifications) is not explicitly present in your raw text or structured inputs, the system will **not** guess it. It will list the item under `missing_specs` and omit it from the rewrite.

> [!IMPORTANT]
> **2. Competitor Data Isolation**  
> IndiaMART listings scraped during competitive scans are used **exclusively** to generate market analysis insights (`competitive_notes`). Competitor specs are **never** copied into your rewritten title, overview, or spec tables to prevent claiming capabilities that belong to other suppliers.

> [!WARNING]
> **3. Automatic Removal of Unverified Claims**  
> The backend guardrail (`guardrail.py`) inspects every output before returning it. Any spec claim or number generated by an LLM that cannot be verified verbatim against your source text is automatically stripped from the clean preview and flagged as an unverified claim.

> [!CAUTION]
> **4. Secret Protection**  
> Never commit `.env` files or API tokens to source control. Always configure environment variables via your hosting provider's dashboard (e.g. Render, Vercel, Railway).
